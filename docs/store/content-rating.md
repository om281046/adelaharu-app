# Clasificarea pe vârste și clasificarea conținutului

**Întrebarea pentru Adela, înainte de răspunsuri:** există în cursuri (ex. „Wild Love”) sau în meditații conținut
despre sexualitate, nuditate (inclusiv în videouri sau poze) sau limbaj explicit? Tot ce se vede în aplicație
contează, inclusiv lecțiile cursurilor. Răspunsurile de mai jos presupun **„nu”**; dacă e „da”, vezi notele.

## Apple: Age Rating (App Store Connect › App Information › Age Rating)

Apple folosește din 2025 chestionarul nou, cu treptele 4+, 9+, 13+, 16+, 18+ (obligatoriu din 31 ian. 2026).
Ratingul îl calculează Apple din răspunsuri; nu se alege direct.

| Întrebare | Răspuns |
|---|---|
| Parental controls / age assurance în aplicație | Nu |
| Unrestricted web access (navigare liberă pe internet) | Nu (deschidem doar pagini adelaharu.ro: player, termeni) |
| User-generated content | Nu |
| Messaging and chat | Nu |
| Advertising | Nu |
| Profanity or crude humor | None |
| Horror / fear themes | None |
| Alcohol, tobacco, drug use or references | None |
| Mature or suggestive themes | None (vezi nota) |
| **Medical or treatment information** | **Infrequent/Mild** (informații despre ciclu, cu avertisment; nu e tratament) |
| **Health or wellness topics** | **Yes** (meditații, ciclul menstrual) |
| Sexual content or nudity | None (vezi nota) |
| Violence (cartoon, realistic, graphic) | None |
| Gambling, simulated gambling, contests, loot boxes | None / Nu |

Rezultat așteptat: **13+ sau 9+** (nesigur: Apple nu publică exact formula pentru temele de sănătate).
Recomandare: dacă ratingul calculat e mai mic de 13+, setați „Age Rating Override” la **13+** (sau 16+), fiind
o aplicație pentru femei adulte despre ciclul menstrual.
**Notă:** dacă în cursuri există teme de sexualitate (educativ), răspundeți „Mature or suggestive themes:
Infrequent/Mild” și, după caz, „Sexual content: Infrequent/Mild”; ratingul urcă probabil la **16+**. E în regulă.

## Google Play: chestionarul IARC (Conținutul aplicației › Clasificarea conținutului)

- Email de contact pentru IARC: contact@adelaharu.ro
- Categoria: **„Toate celelalte tipuri de aplicații”** (All Other App Types; nu e joc, nu e rețea socială).
  *Nesigur:* dacă formularul oferă „Referințe, știri sau educație”, se poate alege și aceea; răspunsurile sunt aceleași.

| Întrebare | Răspuns |
|---|---|
| Violență, sânge, frică | Nu |
| Sexualitate, nuditate | Nu (vezi nota de sus) |
| Limbaj licențios | Nu |
| Substanțe controlate (droguri, alcool, tutun) | Nu |
| Umor vulgar | Nu |
| Jocuri de noroc (reale sau simulate) | Nu |
| Utilizatorii pot interacționa sau schimba conținut între ei | Nu |
| Aplicația partajează locația utilizatorului cu alții | Nu |
| **Aplicația permite cumpărarea de bunuri digitale** | **Nu** (nimic nu se vinde în aplicație) |
| Acces nerestricționat la internet | Nu |
| Conținut generat de utilizatori | Nu |

Rezultat așteptat: PEGI 3 / ESRB Everyone / USK 0 (sau PEGI 12 cu temele medicale; e calculat automat).

**Public țintă** (secțiune separată în Play): doar **18+**. Asta nu schimbă clasificarea IARC, dar spune Google că
aplicația nu se adresează copiilor.
